# Before you start: setup and requirements

What a person needs before a project starts, in the words to use with someone who is not technical. The `get-ready` skill walks through this; keep each message short and ask one thing at a time.

## 0. First time using Claude this way?

If the person has never used Cowork or Claude Code, take them through `references/first-time-setup.md`, one step at a time; they never need to read it themselves. In short: a paid plan (Pro, Max, Team or Enterprise); the Claude desktop app on a Mac or Windows computer; Project Method installed from Wheelhouse's plugin library (`pricemethod/wheelhouse-plugin`) and switched on (on a work plan an administrator may need to allow plugins); a project folder; a Cowork session with that folder connected; Allow when their computer asks; then "Start Project Method". Some button names vary between versions of the app; say "check in your app" rather than guessing.

## 1. Where to use it

- **Use Claude in Cowork** (in the Claude desktop app), or Claude Code. Both work in a folder on your computer, so your project's files are kept between conversations.
- **Switching from Chat to Cowork:** the switch between **Chat** and **Cowork** is only on the start screen, never inside a conversation. Click **+ New** (top of the left sidebar), then choose **Cowork** at the bottom left of the message box, next to **Chat**. This is the step people most often miss.
- **Or in chat, with a Claude Project** (the website, or Chat in the desktop app). There is no folder, so Claude hands you the project's files as you go and you add them to the Project; every conversation in that Project can read them. Good for plans, documents, reports and analyses, and for a page a team can use that Claude refreshes when asked. A scheduled refresh, software that runs without Claude, and anything that needs an API key need Cowork; you can plan in chat and move later (`references/chat-mode.md`).
- **Not the phone app** for the work itself: it can't hold the project's files.
- **Why a folder, in plain words:** Your project is a small set of files that Claude writes and then rereads at the start of every session: the plan, the rules it follows, and a log of what is done. That's what lets you stop and pick up days later without starting over. In a folder on your computer Claude keeps them up to date itself, and they stay yours. A chat or a Claude Project can hold files you upload but Claude can't update them there, so in chat you keep them: Claude hands you each new version and you replace the old one.
- How to tell: Claude can tell you which folder it is working in, and a file it creates shows up in that folder in Finder (or File Explorer).

**Say it like this:** "I keep your project as a few files, the plan, the rules and a log of what's done, and reread them every time we talk, so you can stop and pick up later without starting over. There are two ways to do that. In Cowork, in the Claude desktop app, I save them in a folder on your computer for you; to switch, click + New at the top of the left sidebar, then choose Cowork at the bottom left of the message box (it's only on that start screen, not inside a chat). Or we can work right here: I hand you the files as we go and you keep them in a Claude Project. Which would you like?" Before offering, ask whether they are in the desktop app or on the website; you can't tell from a chat, so never guess.

## 2. A folder just for this project

- **Make a new, empty folder** and name it after the project (for example "Guest Welcome Guide"). Inside your Documents is a good place.
- **Not your whole Desktop, Documents or Downloads folder**, and not your home folder: the project's files would mix with everything else.
- **One project per folder.** A second project gets its own folder.
- If the folder syncs to the cloud (iCloud, Dropbox, OneDrive, Google Drive), that is fine and keeps a backup; just don't work on the project from two computers at the same time.

## 3. Letting Claude work in that folder

- Claude will ask before it creates or changes files. For this folder, say yes.
- It works only in this folder. It never needs your other files.
- It may ask to run a small check (a "helper script"). These only read the project's files and never change anything; it tells you before running one.

## 4. What to have handy (nothing is required)

- **Your idea in a sentence or two.** Rough is fine.
- **Who decides.** The person answering the questions should be the one who makes the decisions, or have them nearby.
- **Any deadline**, as a date.
- **Files you already have** that the project uses (a spreadsheet, a document): make a copy into the project folder when Claude asks. If they hold private details (door or lockbox codes, guests' names or phone numbers), say so; remove what you can.
- **No passwords or keys.** None are needed to start. If the project needs one later, Claude will tell you where it goes. Never paste one into the chat.

## 5. Nothing to install

- You do not need to install anything to start. Claude will not install software on your computer.
- The helper checks use Python, which most computers already have. If yours does not, everything still works; Claude does the same checks by reading the files.
- For some software projects, a later step (the first story) proposes how it will be built and run, with any cost, and you choose. Nothing is set up before you agree.

## 6. How the sessions go

- **One step at a time.** Each working session usually covers one step (we call them stories). You can stop at any point.
- **Coming back:** open the same folder in Cowork and say "Where are we?". Claude reads the files and tells you where things stand and what is next.
- **The first session** is about 17 short questions, a few at a time, each with an example (about 10 in the quick version for a small, one-time thing). You can stop halfway and pick it up later. At the end you get a one-page summary to check, then a step-by-step plan.
- **Your yes matters.** Claude stops to show you its work at the planned points, and always asks before anything that sends, publishes, deletes, pays or changes real information.

## 7. Privacy and safety in one breath

Never paste passwords, keys or codes into the chat. Personal details in your files are kept out of the chat and the notes. Nothing is sent or published without your yes, and the first time anything real is done, it is done once, for one, before everyone.
