## How we check data and analysis work

1. **Definitions first:** every measure is written down in plain words (what is counted, over what period, what is left out) before any number is produced.
2. **Read-only by default:** the work reads from the source and never changes it.
3. **Small pinned sample:** keep a small real example with the answer worked out by hand, and make sure the work reproduces it exactly.
4. **Compare with an independent source:** get the same figure a second way (the source's own report, a manual count, a different method) and reconcile every difference. A match you cannot explain is not a match.
5. **Break it on purpose:** change an input or a rule and confirm the result changes the way you expect and that the check notices.
6. **Edge cases:** empty periods, a single record, missing values, duplicates, the first and last day of a range.
7. **Say what was and was not checked:** next to every result handed over, including what the data cannot tell us.
