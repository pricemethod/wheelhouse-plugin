# Before anything that cannot be undone

Use this checklist before any action that reaches outside the project folder or cannot be taken back: sending an email or message, publishing or posting, deleting, paying or charging, submitting a form, uploading or sharing, or changing data that someone else relies on. Go through every line, every time. An earlier yes does not count for a new action.

## Before
- [ ] **Is this action in the plan for this story?** If not, stop and ask; do not improvise one.
- [ ] **Has it been tried on the test copy or test inbox** (the safe place named in `SAFETY.md`), and did it work there?
- [ ] **Is this the first time it is done for real?** Then do it for **one** real target only, check the result, and only then do the rest, with another yes ("try it once first").
- [ ] **Show the owner exactly what will happen:** the target (who, which address, which page, which records), the content or values, the amount, and how many.
- [ ] **Get a fresh, clear yes to that exact action.** Not a yes from earlier, not "probably", not silence.
- [ ] **Know how it would be undone** (or say plainly that it cannot be).
- [ ] **Stay within the limits:** no more requests than the system allows; slow down when told to.
- [ ] **Keep secrets private:** a key or login is read from its private file and never shown in the chat or the log.

## After
- [ ] **Check it worked** the way the owner would: the email arrived, the page shows, the record changed, and nothing else changed.
- [ ] **If part of it worked and part did not, say exactly which.** Partial success is not success.
- [ ] **Write it in the log:** what was done, to which target, when, the owner's yes, and what you checked.
- [ ] **If anything went wrong, stop and tell the owner before doing anything else.**
